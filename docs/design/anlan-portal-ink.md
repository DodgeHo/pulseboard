# ANLAN.STORE Ink Landscape Direction

## Direction contract

**THESIS:** ANLAN.STORE reads as one illustrated engineering scroll: the landscape gives the portfolio a cultural point of view, while projects remain the evidence and the visitor's next step.

**OWN-WORLD:** Cool mist-blue paper, restrained plum ink, mineral teal, violet mountain layers, and a small cinnabar accent replace the former midnight signal palette. Contour strokes and transparent pigment washes form the shared material language; controls remain precise and readable.

**STORY:** Recruiters meet Dodge and the strongest live work first, scan the ordered project records, then follow the same visual path into the full archive and each project record.

**FIRST VIEWPORT:** A layered mountain wash spans the page behind the existing identity and live-evidence composition. The top navigation stays dark plum for legibility; project names, profile actions, language selection, and the live-work action remain immediately scannable.

**FORM:** A deterministic, resize-aware Canvas scene uses authored ridge paths, translucent pigment layers, contour marks, and a mist band. It is decorative only; all copy, links, filters, status, and project data remain semantic HTML.

**FINISH:** The homepage, archive, and project-detail pages are verified in four locales and at desktop, tablet, and mobile widths; reduced-motion mode is static; production deployment waits for separate user confirmation.
